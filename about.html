ℹ️ 关于本站 ​

Scorpio Pages 是我的个人综合内容档案馆，承载三类完全不同维度的内容创作：

  • 📄 Paper 文库 — 博士阶段阅读的学术论文精读笔记，涵盖计算机视觉、自然语言处理、AI 安全等研究方向
  • 🎮 游戏攻略 — 个人通关游戏的原创攻略，包含主线流程、隐藏要素、配装数据等
  • 🎵 音乐乐评 — 专辑深度聆听笔记，从编曲、歌词、情感多维度记录音乐感受

🏗️ 网站架构 ​

本站使用 VitePress 构建，Markdown + Vue 驱动，全静态页面，无需后端服务。

特性实现方式
构建框架VitePress 1.x + Vue 3
全文搜索VitePress Local Search
LaTeX 公式markdown-it-mathjax3
Mermaid 图表vitepress-plugin-mermaid
代码高亮Shiki (VitePress 内置)
自动部署GitHub Actions → GitHub Pages
托管地址https://azscorpio.github.io/Scorpio_Pages

✍️ 如何新增内容 ​

  1. 在对应分区文件夹新建 .md 文件
  2. 填写完整的 Frontmatter 元数据
  3. 使用 Markdown 撰写正文
  4. 图片放入 docs/assets/ 下对应子文件夹
  5. 提交并推送到 main 分支，GitHub Actions 自动部署

💡

无需修改任何配置代码，站点会自动为新页面生成导航和索引。
