## 一、宁姆格福 — 新手区域

### 1.1 开局建议

<div class="spoiler-block">

**职业选择推荐（新手向）**：
1. **流浪骑士** — 最均衡，自带 100% 物防盾
2. **武士** — 高敏捷，初始武器强力
3. **预言家** — 初期有治疗魔法，容错率高

**关键路线**：
1. ❗ 先到 **关卡前方** 赐福点激活梅琳娜
2. 🎯 等级达到 20+ 再挑战 **恶兆妖鬼**
3. 💡 向南前往 **啜泣半岛** 刷魂和收集圣杯露滴

</div>

### 1.2 重要道具位置

| 道具 | 区域 | 用途 |
|------|------|------|
| 🛡️ 金黄铁盾 | 关卡前方附近 | 100% 物理减伤 |
| 📖 战灰：鲜血斩击 | 亚基尔湖北方废墟 | 前期强力战技 |
| 🧪 圣杯露滴 ×5 | 各地小教堂 | 提升元素瓶回复量 |
| 🗺️ 地图碎片 | 各区域石碑 | 解锁地图 |

## 二、史东薇尔城

### 2.1 主线路线

```
关卡前方 → 史东薇尔正门（或侧门潜行）→ 城墙塔 → 
升降机旁小路 → 接肢葛瑞克 → 获得大卢恩
```

### 2.2 BOSS 战：接肢葛瑞克

**推荐等级**：30-40
**弱点**：⚡ 雷属性
**逃课打法**：

1. 召唤 **涅斐丽·露**（雾门前金色 summon sign）
2. 使用 **离群野狼** 灵魂召唤
3. 保持中距离，等他使用跳劈后翻滚背刺
4. P2 龙头攻击时向侧前方翻滚

<div class="spoiler-block">

**💡 隐藏路径**：史东薇尔城底层有一个隐藏升降机通往 **深根底层**，需要击败 **熔炉骑士** 获取钥匙。

</div>

## 六、避坑提示 🚨

1. ❌ **不要恶意攻击 NPC** — 赎罪需要消耗道具
2. ❌ **别在火山官邸提前击杀拉卡德** — 会锁掉重要支线
3. ❌ **注意陷阱宝箱** — 会被传送到高级区域
4. ⚠️ **出血流在后期依然强势** — 双曲剑跳劈是版本答案
